Simple Linux

2026

Python pywebview PyQt6 JavaScript HTML / CSS Linux

<Caracteristici>

  • • Vizualizator de pagini man cu traducere DeepL — caută orice comandă și traduce textul selectat instant
  • • Panou servicii — explorează toate serviciile systemd cu status, PID și comenzi gata de copiat
  • • Jurnale sistem — explorează logurile pe categorii (Sistem, Kernel, Auth, Boot, Aplicații) cu căutare și control linii
  • • Sarcini programate — vezi toate timerele systemd și joburile cron cu programul și ora următoarei rulări
  • • Informații sistem în timp real — CPU, RAM, GPU, disc, rețea și uptime actualizate la 2 secunde
  • • Variabile de mediu — caută și copiază orice variabilă cu un singur click

<Descriere>

Simple Linux a început ca un simplu vizualizator de pagini man. În timp a crescut într-un instrument mai amplu pentru explorarea și înțelegerea unui sistem Linux — construit pentru începători, util pentru toată lumea.

Scopul aplicației este să fie un punct de plecare, nu un instrument permanent. Îi ajută pe începători să înțeleagă sistemul vizual mai întâi — și apoi să treacă treptat la utilizarea terminalului direct. Fiecare informație afișată în aplicație poate fi obținută și prin comenzi de terminal, iar învățarea acestora este pasul natural următor.

Aplicația este construită cu Python pe backend și HTML, CSS și JavaScript vanilla pe frontend, conectate prin bridge-ul JS al pywebview. Frontend-ul este servit de un server HTTP local pe portul 8765, evitând limitările protocolului file:// și menținând arhitectura simplă. Toate datele de sistem sunt obținute prin instrumente CLI standard Linux precum systemctl, journalctl și man via subprocess — făcând aplicația fiabilă pe diferite distribuții.

Gestionarea proceselor a fost omisă intenționat. Instrumente precum htop și btop sunt standardul pentru aceasta pe Linux — sunt mai rapide, mai puternice și nu pot fi înlocuite de o interfață grafică. Simple Linux îi încurajează pe utilizatori să învețe și să folosească aceste instrumente direct.

*Acest proiect a fost realizat cu ajutorul AI.
