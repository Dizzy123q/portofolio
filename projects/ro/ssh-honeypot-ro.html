SSH Honeypot

2025

Python Docker Flask Paramiko Debian 12

<Funcționalități>

  • • Izolare Docker per atacator — fiecare sesiune rulează într-un container Debian 12 cu restricții de rețea
  • • Analiză comportamentală automată — comenzile sunt clasificate în 10 categorii de atac cu scor de severitate per comandă
  • • Reconstrucția fazelor de atac — mapare cronologică pe faze: Recunoaștere, Exploatare, Persistență și Curățare
  • • Profilarea atacatorului — scor de expertiză și clasificare (Începător / Intermediar / Avansat / Expert)
  • • Dashboard web — statistici în timp real, browser de sesiuni și rapoarte HTML forensice per sesiune

<Descriere>

Un SSH honeypot high-interaction dezvoltat ca proiect de disertație în securitate cibernetică. Sistemul acceptă conexiuni SSH inbound indiferent de credențiale și rutează fiecare sesiune într-un container Docker dedicat cu un mediu Debian 12 realist — cu fișiere-capcană, utilizatori fictivi și un bash history pre-completat. Activitatea atacatorului este logată și procesată printr-un pipeline de analiză în două niveluri care reconstruiește timeline-ul atacului, clasifică comenzile în 10 categorii comportamentale, evaluează expertiza atacatorului și generează rapoarte HTML forensice per sesiune. Rezultatele sunt agregate într-un dashboard Flask cu distribuție geografică, distribuția categoriilor de atac și analiza pattern-urilor temporale.
