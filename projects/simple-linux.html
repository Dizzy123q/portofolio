Simple Linux

2026

Python pywebview PyQt6 JavaScript HTML / CSS Linux

<Features>

  • • Man page viewer with DeepL translation — look up any command and translate selected text instantly
  • • Services dashboard — browse all systemd services with status, PID and ready-to-copy terminal commands
  • • System logs — explore logs by category (System, Kernel, Auth, Boot, Applications) with search and line count control
  • • Scheduled tasks — view all systemd timers and cron jobs with their schedule and next run time
  • • Real-time system info — CPU, RAM, GPU, disk, network and uptime refreshed every 2 seconds
  • • Environment variables browser — search and copy any variable with one click

<Description>

Simple Linux started as a simple man page viewer. Over time it grew into a broader tool for exploring and understanding a Linux system — built for beginners, useful for everyone.

The goal of the app is to serve as a starting point, not a permanent tool. It helps beginners understand their system visually first — and then gradually transition to using the terminal directly. Every piece of information shown in the app can also be obtained through terminal commands, and learning those commands is the natural next step.

The app is built with Python on the backend and vanilla HTML, CSS and JavaScript on the frontend, connected through pywebview's JS bridge. The frontend is served by a local HTTP server running on port 8765, which avoids file:// protocol limitations and keeps the architecture simple. All system data is fetched through standard Linux CLI tools like systemctl, journalctl and man via subprocess — making the app reliable across different distributions without depending on Python libraries that may not be available everywhere.

Process management was intentionally left out. Tools like htop and btop are the standard for this on Linux — they are faster, more powerful, and cannot be replaced by a graphical interface. Simple Linux encourages users to learn and use these tools directly.
